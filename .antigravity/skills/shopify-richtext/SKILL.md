# Shopify Rich Text Input

This skill covers how to implement and style Shopify's rich text settings effectively.

## Setting Types

### 1. `richtext`
- **Use for**: Long-form content, descriptions, or any text requiring multiple paragraphs, lists, or links.
- **Output**: Automatically wraps content in `<p>` tags. Can include `<ul>`, `<li>`, `<a>`, `<b>`, `<i>`.
- **Implementation**:
  ```liquid
  <div class="rich-text-container">
    {{ block.settings.text }}
  </div>
  ```

### 2. `inline_richtext`
- **Use for**: Short, single-line text where bold, italic, or links are needed, but **without** paragraph wrapping.
- **Output**: Pure inline HTML (e.g., `text <b>bold</b>`). No `<p>` tags.
- **Implementation**:
  ```liquid
  <p class="inline-text">
    {{ block.settings.text }}
  </p>
  ```

## Best Practices

### 1. Avoid Tag Nesting Issues
Since `richtext` (standard) outputs its own `<p>` tags, **never** wrap it in another `<p>` tag. This causes invalid HTML and layout breaks in browsers.
- **Wrong**: `<p>{{ block.settings.text }}</p>` -> Results in `<p><p>...</p></p>`
- **Right**: `<div class="rich-text-wrapper">{{ block.settings.text }}</div>`

### 2. Styling Nested Elements
Because the HTML is generated by the merchant, you must style the tags directly using descendant selectors.
```css
.rich-text-wrapper p { margin-bottom: 1rem; }
.rich-text-wrapper a { text-decoration: underline; }
```

### 3. SEO & Plain Text
If you need to use rich text content in an SEO tag or a `title` attribute, use the `strip_html` filter.
```liquid
<meta name="description" content="{{ block.settings.text | strip_html }}">
```

### 4. Handling Empty Content
Always wrap your output in a blank check to avoid rendering empty containers.
```liquid
{%- if block.settings.text != blank -%}
  <div class="mptt-description">
    {{ block.settings.text }}
  </div>
{%- endif -%}
```
